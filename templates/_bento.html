{# ═══════════════════════════════════════════════════════════════════════ BENTO — SHARED SHELL Every page in this codebase is a standalone document: only app_base and client_base use inheritance, so the other ~40 templates each hand-roll their own and topbar. That is why the old design drifted -- a change to the header had forty places to land and never reached them all. These macros are the one place the shell lives now. They are macros rather than a base template on purpose: the pages are standalone documents with wildly different body structures, and converting all of them to `{% extends %}` in one move would be a far larger diff than re-skinning them. A page calls head() and topbar() and keeps full control of everything between. Imported with context so `brand` (from brand.py, via the app context processor) and `user` resolve without being threaded through every call. Usage: {% from "_bento.html" import head, topbar with context %} {{ head("Contact Finder", ["company_people_intelligence.css?v=28"]) }} {{ topbar([(brand.agents_plural, "/p2/strategic-agents"), ("Contact Finder", none)]) }} ═══════════════════════════════════════════════════════════════════════ #} {# ── head ─────────────────────────────────────────────────────────────── title page name; the product name is appended here so no page has to remember the separator or the brand string sheets page stylesheets, each "name.css" or "name.css?v=N". The three system sheets are always loaded first and never passed in. scripts page scripts, same form. bento-motion.js is always loaded. ──────────────────────────────────────────────────────────────────────- #} {% macro head(title, sheets=[], scripts=[]) -%} {{ title }} · {{ brand.name }} {# Order is load-bearing: tokens define the variables the other two read, and motion overrides nothing but adds the animation layer. #} {%- for sheet in sheets %} {%- set name, _, ver = sheet.partition('?') %} {%- endfor %} {%- for script in scripts %} {%- set name, _, ver = script.partition('?') %} {%- endfor %} {# Deferred so it never blocks paint, and because it only needs the DOM. #} {%- endmacro %} {# ── topbar ───────────────────────────────────────────────────────────── crumbs a list of (label, href) pairs. A pair whose href is falsy is the current page and renders as text rather than a link, so a page cannot accidentally link to itself. No theme toggle: this design system is a single dark theme rather than a light/dark pair, so the control would have nothing to switch between. ──────────────────────────────────────────────────────────────────────- #} {% macro topbar(crumbs=[]) -%}
